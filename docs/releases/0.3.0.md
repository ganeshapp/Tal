# Tal 0.3.0

The first public Tal release establishes an offline training foundation: human-like opponents, interactive game review, opening practice and adaptive puzzles.

Tal's long-term goal is to help you develop attacking, creative chess inspired by Mikhail Tal: see sacrifices, build initiative, explore imaginative continuations and pose difficult problems for human opponents. The README roadmap describes the planned Tal game studies, attacking exercises, repertoire work and more useful feedback on creative decisions. Those specialized training features are planned for future iterations.

## Install

- **Mac:** download `Tal-0.3.0-arm64.dmg`, open it and drag Tal into Applications. Apple Silicon; macOS 12 or later. This build is ad-hoc signed and is not Apple-notarized.
- **Android:** download `Tal-0.3.0-android-arm64.apk` and install it on an ARM64 device running Android 7 or later. This early release uses a development signing key.

Both installers include all engines and training data. No account, connection or additional download is needed to play. The app has a new application identifier; previous prototype saves are not imported.

## Included

- Native Maia 3 with 600–2600 skill settings and Stockfish analysis.
- Tap and drag, premoves, takebacks, promotion selection and clear checkmate results.
- Interactive review with move categories, evaluation graph, autoplay, engine lines, arrows and alternative branches.
- Game filters for color, result, opponent rating and opening.
- A searchable catalogue of 3,865 opening lines, rehearsal and play from an opening.
- 19,050 offline puzzles, adaptive local Glicko-2 ratings, mixed/themed selection and ±100/200 difficulty choices.
- Per-theme ratings, radar chart, improvement areas, history, replay, Streak and 3/5-minute Storm.

## Verification and limits

The release is checked with the automated rules, interaction, persistence, rating and native-engine suite. See `build-report.json` for the exact results, asset hashes and installer sizes. Every bundled puzzle solution and opening line is validated.

Maia skill settings are model inputs, not independently calibrated playing ratings. Puzzle ratings remain local. Great and brilliant labels are heuristics; analysis has a time budget and displays the achieved depth. Analysis branches are session-local. Native engines require the desktop or Android app; iOS is not validated.
